// Pipeline

Under the hood

Commands copied from each project’s own README — no invented flags, no fake benchmarks.

ROM conversion & verification

OpenROM

Magic-byte platform detection feeds the right chdman profile: createcd for PS1, Dreamcast, Saturn and Sega CD, createdvd for PS2, GameCube, Wii and Xbox.

openrom-core — headless CLI 
# 20+ paths: ISO, BIN, CUE, GDI, IMG, ECM, CHD, CSO, ZSO, XISO, RVZ, WIA, WBFS, GCZ
$ openrom-core --detect game.iso
$ openrom-core --input game.iso --format CHD
$ openrom-core --input game.iso --format CHD --verify
$ openrom-core --folder /roms/ --format CHD --compression Max
$ openrom-core --json --hash game.iso

macOS binaries without a Mac

Masa

A clean-room stub SDK plus clang and LLVM’s ld64.lld produce real Mach-O executables; the Danroot loader then runs them in-process on Linux or Android.

masa — v1.8.1 
# 1. clean-room stub SDK, nothing downloaded from Apple
$ masa sdk init-stub /opt/masa/sdk
# 2. cross-compile a real Mach-O executable
$ MASA_SDK_PATH=/opt/masa/sdk masa cc hello.c -o hello
# 3. run it right here, in-process
$ masa danroot ./hello
hello from a Mach-O binary running on Linux!
# 4. package a UDIF disk image
$ masa pack --dmg DemoApp.app -o DemoApp.dmg

Visual Basic 6 → native C99

VBX

The Go compiler parses .vbx, infers types, emits standard C99 and hands it to your system C compiler with -O2 — one standalone binary, zero runtime.

vbx — v0.1.0-alpha 
# transpile, compile and execute in one step
$ vbx run examples/interactive_app.vbx
# build a standalone native binary
$ vbx build examples/popup.vbx -o my_cool_app
# keep the generated C for inspection
$ vbx build examples/popup.vbx --keep-c
$ vbx version

UMD Video, played natively

UMDPlay

DiscReader picks the ISO 9660/UDF or CHD (libchdr) backend by extension, then the in-memory PsmfDemuxer feeds UMDPlay’s own ATRAC3+ and H.264 decoders. No firmware, no emulator, no FFmpeg.

umdplay — native core 
# ISO and CHD are byte-identical playback paths
$ umdplay /path/to/movie.iso
$ umdplay /path/to/movie.chd
# mute the runtime-synthesised WMC navigation sounds
$ umdplay /path/to/movie.chd --no-ui-sounds

Retro hardware, modern toolchains.

OpenROM is the flagship: a Dart/Flutter toolkit that turns a drawer of mismatched ISO, BIN, CUE and GDI files into verified CHD, CSO or RVZ archives, and ships the GUI and a headless CLI in the same release.

The rest of the portfolio follows the same rule — solve a real problem, then remove the dependency you did not need. Masa builds and runs Mach-O binaries without Apple tooling. VBX brings Visual Basic 6 back by compiling to C99. UMDPlay plays UMD Video with its own decoders and no firmware.
