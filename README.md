# M5Devs.github.io

Portfolio site for the M5 Dev open-source studio. Single file, no build step:
open `index.html` directly, or serve the folder (`python3 -m http.server`).

- Live: https://m5devs.github.io
- Code: https://github.com/M5Devs
- Models and datasets: https://huggingface.co/M5-Dev

Every statistic, project description and link on the page was read from the
GitHub and Hugging Face APIs on 2026-11-26.
